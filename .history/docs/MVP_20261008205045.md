# StayInCanada MVP Scope

## 1. Core MVP (Focus Now)

Core workflow: **Client Intake → Document Collection → Application Progress**

These are planned, not yet proven. Next step: prototype and test with real users.

### Foundation: Login

- **Client, Staff and Admin Login**: separate experiences and access by user role

### 1. Client Intake

Help clients complete the CIF easily.

- **Sectioned Client Intake**: break the CIF into smaller sections
- **Save and Continue**: leave the intake and come back later
- **Intake Progress**: show how much is completed
- **Field Guidance and FAQs**: explain why information is needed
- **Information Reuse** _(potential AI)_: reuse information already provided
- **Conditional Questions** _(undecided)_: change or skip questions based on answers and application type

### 2. Document Collection

Clients submit documents; staff review them.

- **Document Checklist** _(potential AI)_: show which documents are required
- **Document Uploading**: upload directly to each requirement
- **Document Status**: required, submitted, under review, changes required, approved
- **Document Resubmission**: replace documents after staff request changes
- **Staff Review and Approval**: review submissions before approving
- **Contextual Staff Feedback**: comment directly on a document, question, or requirement

### 3. Application Progress

Show clients where they are and what to do next.

- **Application Progress Tracker**: show the current stage of the immigration process
- **Application Guidance** _(potential AI)_: explain each stage and the next steps
- **Clear Next Actions**: show whether the next step belongs to the client or staff
