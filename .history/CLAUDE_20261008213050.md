## Development Process

Enforce TDD workflow. Use /sync (preflight), /plan (design plan), and /done
(validate).
Refer to docs/DECISIONS.md and docs/IMPLEMENTATION_PLAN.md for context before work.
Dev server: npm run dev (Next.js).

## Security

- Runtime: work only inside this project folder; never use sudo or admin rights.
- Scanning: Use security-auditor agent for OWASP checks.
- Secrets: Never commit .env, keys, or tokens (use .env.local).

## Code Style

- Types: Required (TypeScript, strict mode).
- Components: Functional components + hooks only.
- Formatting: No special Unicode in code/output.

## Design System (shadcn/ui + Base UI)

- UI: use only shadcn/ui components from components/ui. Base UI is the
  primitive library (not Radix), so do not use asChild; use the render prop.
- Missing component: run "npx shadcn@latest add <name>" before writing custom UI.
- Styling: use only tokens/CSS variables in globals.css. No hard-coded hex colours.
- Do not edit generated files in components/ui unless asked; wrap them instead.
- Keep components/ui presentational (props in, markup out); fetch data in app/ pages.
